Running tests

To run JUnit tests from the command line, you need the JUnit Platform Console Standalone JAR. The runner executes: 

java -jar junit-platform-console-standalone.jar -cp . --select-method CalculatorTest#testAdd

Configure the JAR path and classpath when creating the syntax adapter:

junit({
  jar: "path/to/junit-platform-console-standalone.jar",
  classpath: "build/classes/java/test"
})
