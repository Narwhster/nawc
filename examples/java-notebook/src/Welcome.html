How it works

NAWC uses two syntax adapters for Java: @nawc/syntax-java for general Java source and @nawc/syntax-junit for JUnit test methods. Both use java-parser to parse Java source files and extract declarations.

Referencing code

Use <ref file="..." syntax="java" name="..." type="..."> to display specific declarations. Supported types: class, interface, enum, method, constructor.

Running code

Use <runnable file="..." syntax="java"> to run a whole file or class. For static methods, the adapter uses JShell. For JUnit tests, use syntax="junit" to run specific test methods via the JUnit Platform Console.
