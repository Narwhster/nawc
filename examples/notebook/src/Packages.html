Workspace map

The monorepo separates framework contracts from concrete editor, agent, and language integrations.

Framework packages

  • packages/nawc: public entry point, CLI, config loading, HTTP/SSE server, file workspace, watcher, runners, and generated skills.
  • packages/create-nawc: interactive scaffolder used by package-manager create commands.
  • packages/config: shared source, run, provider, syntax, and notebook configuration types plus runtime validation.
  • packages/plugin: server-side plugin metadata and browser-side Tiptap extension contracts.
  • packages/ui: React/Tiptap notebook shell, note navigation, canonical serialization, wiki links, and prompt panel.

Concrete integrations

  • plugins/core: declares the interactive, ref, and runnable nodes and ships their Tiptap node views.
  • plugins/nawc-skills: contributes the NAWC authoring workflow skills.
  • provider/codex: launches the local Codex CLI and translates its JSONL event stream.
  • plugins/typescript: extracts whole files or named TypeScript declarations and runs files through tsx.
  • plugins/vitest: extracts exact it/test calls and runs Vitest with an optional title filter.
  • examples/notebook: this dogfood notebook, configured with every integration above and a base directory at the monorepo root.

UI composition

The application is a three-column shell: notes on the left, the active Tiptap document in the center, and provider interaction on the right. The UI uses React, Tiptap, Tailwind CSS, shadcn-style components, Radix UI primitives, and Lucide icons.
