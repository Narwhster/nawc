CLI and notebook workflow

Create a notebook

Run pnpm create nawc, or the corresponding npm, Yarn, or Bun create command. The creator accepts an optional directory, detects the invoking package manager, can be overridden with --package-manager, and supports --no-install.

Scaffolding refuses a non-empty target. It writes a private ESM package, a nawc script, config, a welcome note, README, and gitignore entries for dependencies and generated skills. Unless disabled, it then invokes the selected package manager's install command.

Configure it

plugins add editor nodes, syntax adapters, and skills; provider handles agent prompts; baseDir defines the repository boundary. port is optional and must be between 1 and 65535.

Run it

From the notebook directory, run pnpm nawc. The default URL is http://localhost:6292. Use nawc --port <number> or a config port to change it, and --config <file> for a different config path. SIGINT and SIGTERM close the watcher, Vite server, and HTTP server.

Author notes

  • Create and delete notes from the sidebar; nested HTML paths are supported by the file API.
  • Edit prose with Tiptap and StarterKit's familiar Markdown-style input rules.
  • Type [[Architecture]] to create a navigable wiki link.
  • Hover a core node for delete and agent actions. Interactive nodes also expose source editing; runnable nodes expose Run.
  • Use the right panel for note-scoped prompts. $skill and @file text is passed unchanged to the provider.

Generated skills

At startup, plugin skills are written beneath .skills/<skill>/SKILL.md. NAWC marks generated files and refuses to overwrite an unmarked, user-owned skill. The creator ignores .skills by default because these files are derived from installed plugins.
