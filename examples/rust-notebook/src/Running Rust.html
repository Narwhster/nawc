Running Rust

NAWC can run a whole Rust file or invoke a single function, using the rust syntax of @nawc/syntax-rust.

Requirements

Runnable blocks for the rust syntax require the cargo-eval subcommand:

cargo install cargo-eval

The script

src/fibonacci.rs is a self-contained script: it is not part of the cargo library, so it can run on its own.

Invoke a single function

With type="fn" and a name, the file is compiled and run with cargo eval --expr, invoking the named free function with no arguments. The function must be a free function (not a method) and must take no arguments.
