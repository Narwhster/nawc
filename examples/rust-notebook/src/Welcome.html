How it works

NAWC uses one syntax plugin for Rust: @nawc/syntax-rust. It registers two syntaxes, rust for general Rust source and cargo-test for test functions. Both use the tree-sitter Rust grammar (compiled to WebAssembly) to parse source files and extract items.

Referencing code

Use <code file="..." syntax="rust" name="..." type="..."> to display specific items. Supported types: fn, struct, enum, trait, impl, mod, const, static, type, macro.

Running code

Use <runnable file="..." syntax="rust"> to run a whole file with rust-script, or add name and type="fn" to invoke a single function in the evcxr REPL. For tests, use syntax="cargo-test" to run cargo test for the whole project or a single test name.
