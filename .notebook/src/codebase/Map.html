Codebase map

Use this page when you know the capability you want to change but not its owning package.

  • packages/nawc — CLI, server, workspace safety, note search, editor launching, and generated skills.
  • packages/ui — React shell, Tiptap editor, panes, navigation, prompt composer, and API client.
  • packages/config — shared contracts and default themes/editor integration.
  • packages/plugin — the server and browser plugin shapes.
  • plugins/core — built-in interactive, reference, and runnable editor nodes.
  • provider/codex — Codex process adapter and event translation.
  • plugins/typescript, plugins/vitest, plugins/java, and plugins/junit — focused source selection and runners.
  • plugins/nawc-skills — the NAWC authoring workflow skills.
  • packages/create-nawc — project scaffolding and starter content.
