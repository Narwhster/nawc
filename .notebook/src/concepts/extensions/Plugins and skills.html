Plugins and skills

A plugin extends both sides of the human–agent loop. Its client extensions teach the browser editor new note vocabulary; its skills teach the configured agent how to author that vocabulary correctly.

The core plugin makes the relationship concrete. Its metadata advertises three nodes and embeds a concise authoring skill. Its client implements the corresponding Tiptap nodes, React views, source fetching, prompt actions, terminal UI, and sandboxed interactive rendering.

On startup, NAWC writes generated skills beneath a managed skills directory and labels them as generated. It then merges those skills with provider-discovered skills for the prompt UI. Existing unmarked skill files are protected from replacement.

This is a useful design rule for extensions: represent the same concept in executable editor behavior and in agent-readable instructions, but keep source code itself live through references rather than copying it into notes.
