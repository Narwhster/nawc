Configuration internals

Configuration is dependency injection for the whole notebook. One typed object chooses plugins, one provider, zero or more syntax adapters, the project boundary, editor integration, theme, and port.

defineConfig uses a Zod shape for runtime validation while preserving the caller's inferred TypeScript type. It then materializes default VS Code and light-theme values. Syntax lookup accepts either a canonical adapter name or alias.

The theme is data rather than a stylesheet hook: an appearance plus a record of CSS variables. This lets the server serialize the selected design system to the client while keeping built-in themes and custom themes on the same contract.

baseDir is the most consequential setting. It becomes the root for safe source paths, runner working directories, editor targets, provider prompts, and provider skill/model discovery. See [[Configuration and themes]] and [[Safe notebook workflows]].
