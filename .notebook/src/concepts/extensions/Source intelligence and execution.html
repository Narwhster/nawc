Source intelligence and execution

A source element stores a selection—not copied code. The server reads the current file under baseDir, finds the syntax adapter, and asks it to resolve the selection. This keeps explanations synchronized with refactors and makes line-aware editor links possible.

HTML attributes→safe file read→adapter.resolve→live code + lines

The TypeScript adapter traverses a compiler AST and supports functions, methods, classes, type aliases, interfaces, variables, and enums. Function-valued variables expand to their enclosing variable statement. The Vitest adapter instead finds a call with an exact literal title.

Execution is deliberately separate. An adapter's optional run returns argv and cwd; the server validates the selection and starts the process without a shell. This avoids treating note text as shell syntax, but does not make configured commands untrusted-safe.
