Architecture: files connected by small contracts

NAWC is a local React application whose database is a directory of HTML files. A typed config composes four seams: browser plugins, an agent provider, syntax plugins, and an editor launcher. The server joins them without making any one integration mandatory in the others.

Select a component to inspect its responsibility.

Follow a real flow

  1. The CLI loads nawc.config.ts and creates the local server.
  2. The UI fetches a flat note listing, builds a folder tree, and opens HTML in a Dockview panel backed by a Tiptap document.
  3. A <ref> asks the server to resolve current source through a syntax adapter.
  4. A <runnable> opens a same-origin WebSocket. Its adapter supplies argv and cwd, which run in a pseudo-terminal without shell interpolation.
  5. The prompt panel validates selected Git-backed file paths and known skills/models, then streams provider events over server-sent events.
