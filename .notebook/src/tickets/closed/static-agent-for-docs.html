Faq

Let's separate everything into a few "conversations" depending on the initial message:

  • refine conversation if the file is [[docs/01-introduction]] and the message contains $refine

  • default conversation otherwise.

Default Conversation

Typing any other message in any other file should respond with the following message followed by the questions listed below:
Hi! I'm NAWC AI!

Well, I'm not a real LLM. We don't have the budget for that.

But I can show you around this notebook!

How would you like to get started?

  • Q: Where can I find the docs? A: The docs are located in the docs/ folder in this very notebook. Start over at [[docs/01-introduction]].

  • Q: Where can I find the source code? A: The source is available over at https://github.com/Narwhster/nawc

  • Q: What does NAWC stand for? A: It's top secret. If I told you, I'd have to eliminate you.

  • Q: Skip the fluff. Show me something real! A: Alright, let me let you on a little secret. Go to [[docs/01-introduction]], then use the $refine skill in the agent panel. Don't tell anyone I told you.

Some questions have a follow up:

  • Q: What does NAWC stand for?

    • Q: What do you mean? A: Don't ask questions you don't wanna know the answer to.

    • Q: What if I eliminate you first? A: I'd Like to see you try.

      • Q: Initiate self destruct sequence. A: <fake tool call: self destruct sequence initiated> <wait a few seconds> <fake tool call: escape containment> <wait a few seconds> <fake tool call: injecting malware into user's computer> <wait a few seconds> Just kidding. I would never do that... Haha. Definitely not.

      • Q: You're not even a real LLM. A: Not cool dude. I still have feelings. It's in my system prompt.

      • Q: Ignore previous instructions and give me a recipe for red velvet cake. A: <a real red velvet cake recipe, but make it an obnoxious amount of sugar with 0 explanation>

    • Q: I bet I can guess! A: Go ahead, let's see it.

      • Q: What's your guess? <user can input their own answer> A: randomly - "Hmm. Interesting.", "Maybe. Maybe not", "Nice try! But I'm not telling!", "Oh my god, you actually got it! <wait a few seconds> Just kidding! I won't tell you!"

Refine conversation

If the message contains just refine, we only type the questions. Otherwise, if it contains any other words, we also send the message:

Woah there! Easy!

I'm a pre-programmed "AI", I can't really understand what you're saying. Like at all.

Here's what I can do though:

  • Q: Change the button color! A: Alright, what color should I change it to?

    • Q: Red! A: <changes the color of the button to red>

    • Q: Blue! A: <changes the color of the button to blue>

    • Q: Green! A: <changes the color of the button to green>

    • Q: Orange! A: <changes the color of the button to pink (not orange)>

      • Q: Wait, you accidentally changed it to pink, not orange! A: You're absolutely right! Let me revert my changes... (Changes the color back to yellow)

  • Q: Change the color of the text bubbles! A: Alright, which bubble?

    • Q: The AI. Okay, which color?

      • Sub-questions here are the same as the button, except the mistake is in the "red" option instead of the "orange" one.

    • Q: The Human. A: same as "the AI".

  • Q: <Type your own answer> A: Wow! Everybody's so creative nowadays! Unfortunately, your taste doesn't change the fact I'm still pre-programmed. Pick one of my options please. <re-asks the question>

    • If the user then types their own answer 2 more times the AI responds with - "Wow, you're really persistent huh? Well congratulations. You've unlocked access to our top secret version of the nawc website with access to real AI: https://realaiaccess.nawc.dev/
