agent-question-tool

The agent's "question tool" — the structured way for an agent to pause and ask the user a multiple-choice question — currently does not work in NAWC. When an agent emits a request.opened with requestKind for a question, the user-facing side never receives the prompt and the request times out.

This is the prerequisite for [[tickets/product-website]]'s static-site FAQ provider, which is being redesigned around the question tool. Until this ticket is resolved, the FAQ provider has no working interaction primitive to walk its conversation tree.

What needs to be true

  • An agent emits a request.opened event with a question and a list of choices.
  • The agent panel renders the question to the user with clickable options.
  • The user picks an option; the panel emits a request.resolved back to the provider with the chosen label.
  • The provider receives the resolved request and continues the turn with that input.

Open questions

  • Is the timeout a server-side bug (request never fanned out to the client) or a client-side bug (client never subscribed to the channel)?
  • Does the existing ProviderEvent shape cover this end to end, or does the wire protocol need new fields?
  • Should the panel also support free-text input alongside multiple choice, or are questions strictly multiple choice?
