01-cant-copy-errors

Issue

Sometimes source blocks have errors in their implementation. For example - they reference a function that no longer exists. In that case they correctly produce an error, but you can't do anything with it.

Examples

A reference can fail because the requested function is missing from an existing file:

It can also fail because the referenced file does not exist:

Missing Feature

We want to have a way to copy the errors, right now you can't even select the text.

Code blocks with errors should start open rather than collapsed.

We should also add a "fix with agent" option.

Resolution

Failed source blocks open automatically, retain selectable diagnostic text, and expose copy and Fix with agent actions. The agent action supplies a typed diagnostic reference.
