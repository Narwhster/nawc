persist-chat-history

Chats currently only persist in memory. Persist agent threads on the notebook server so users can return to them after a server restart and from any connected browser or device.

Decision: project-local SQLite state

SQLite database at .nawc/state.sqlite inside the notebook directory. The .nawc name identifies the runtime data directory, not the notebook directory. The server owns persistence, so all connected clients share the same chat history.

The notebook's own .gitignore must ignore .nawc/, preserving existing entries. Chat history is runtime state and must not be tracked or included in project file references.

Decision: runtime ignore is part of chat persistence

Adding .nawc/ to the generated notebook .gitignore is part of the same persistence goal because it keeps the project-local chat database as untracked runtime state.

Decision: preserve the full timeline

Persist the complete agent thread projection, not only user and assistant text. This includes turns and plans, tool activities and outputs, warnings, request outcomes, provider/runtime identifiers, reference keys, and message metadata required to render the existing conversation view after restart.

Decision: recover orphaned turns as interrupted

The server owns the projected runtime status. If a process restart leaves a persisted turn marked as running, restore that turn as interrupted and the thread as idle, because no server process is still driving its stream. The provider remains responsible for deciding whether its persisted provider thread can resume when a later turn is sent.

Done criteria

  • A new agent manager loads the stored threads and preserves provider/runtime identifiers, references, metadata, turns, plans, activities, requests, warnings, unknown events, and message content.
  • Threads created, updated, and deleted through the server remain consistent for all connected clients.
  • Persisted active turns restore as interrupted with an idle thread; providers still control later-turn resumption.
  • Generated notebooks add .nawc/ to .gitignore without removing existing entries.
  • Runtime state is excluded from project file listings and prompt references.
  • Focused persistence and generator tests pass.
