Let syntax adapters provide highlighting

Issue

A syntax adapter owns source resolution and optional execution, but source highlighting is implemented independently by the core plugin. The plugin has its own fixed Highlight.js language alias table, so a configured syntax's canonical name and aliases do not determine how its source is highlighted.

Current behavior

resolveSource and startRun locate adapters from config.syntax and call resolve or run. In contrast, sourceLanguage normalizes the raw syntax attribute and file extension against a hard-coded map, then highlightSource invokes highlight.js. A custom adapter can work for extraction while still rendering as plain escaped text.

Prototype

This prototype adds an optional adapter-owned highlighter to the syntax contract.
