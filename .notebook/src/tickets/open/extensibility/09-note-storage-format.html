Make note storage location and extension configurable

Issue

Notebook notes are treated as projectDir/src/**/*.html in many independent places, but the configuration has no note root or document-format contract. Supporting Markdown, a different note directory, or a plugin-owned document store would require changing server, UI, search, and wiki-link code together.

Current behavior

createNawcServer derives srcDir from projectDir. listNotes and listEntries filter for .html, writeNote and renameNote reject other extensions, and App.submitDialog, displayName, and notePath append or remove .html. Search also parses every note as HTML through htmlText.

Prototype

A document-store configuration can centralize the root, extension, and text extraction policy.
