Pass editor context through the open contract

Issue

The editor action distinguishes opening a notebook note from opening project source, but that information is discarded before the configured editor's open function runs. Editors cannot use different URI schemes, workspaces, or commands for notes and source files without guessing from the path.

Current behavior

EditorAction sends scope, line, and column to /api/editor/open. The route uses scope only to choose srcDir or baseDir, then calls launchEditor with an EditorLocation containing only file, line, and column. The NawcEditor contract has no scope field.

Prototype

The proposed contract makes scope part of the editor-owned location.
