Editor icons belong to the editor contract

Issue

The configured editor can provide an icon name, but the UI only recognizes the literal vscode value and renders every other editor with the same generic code icon. Adding an editor therefore requires editing NAWC UI code, and an editor package cannot provide its own recognizable presentation.

Current behavior

NawcEditor exposes an optional string icon, while configuredEditor fetches that metadata for EditorAction. The action uses VsCodeIcon only when the value is exactly vscode; all other values select Code2Icon. The server returns the configured editor's name, label, and icon through /api/meta.

Prototype

This prototype models an editor-owned icon payload rather than a NAWC-owned string switch.
