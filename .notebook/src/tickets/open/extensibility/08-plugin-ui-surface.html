Give plugins app-level extension points

Issue

Client plugins are additive Tiptap extension bundles only. They cannot add a toolbar action, Dockview panel, prompt completion source, editor action, or other app-shell behavior, so meaningful plugin features must be embedded inside a node instead of participating in the surrounding NAWC UI.

Current behavior

NawcClientPlugin contains only a name and an array of Tiptap extensions. Editor always installs WikiLink and StarterKit, then appends configured extensions. Separately, App declares a fixed note panel map and a fixed agent panel; neither consumes plugin-provided UI contributions.

Prototype

The plugin contract could expose declarative toolbar actions and panels alongside editor extensions.
