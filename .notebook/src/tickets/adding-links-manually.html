adding-links-manually

Adding wiki-links manually is currently inconvenient.
We should have some autocomplete happening, with fuzzy finding, otherwise you have to write the full precise notebook path to the note you want to link to.

Also, the syntax is `[[note-path]]` but the only part getting replaced with the link is what's inside the brackets, not the whole thing.

One more bug is that the link is created even for notes that don't exist yet, which is good, but clicking on it doesn't create the missing note. I think we should add the "create note" option to the auto complete, which will open the created note in a new tab. Otherwise it'll just not create the link for notes that don't exist.
