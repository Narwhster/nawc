chats-break-on-refresh

Agent chats currently break when you refresh the page. They no longer receive updates from the agent. So for example, an agent can be done with work but it'll still show only up to the last tool call/message it sent, and show the stop button in the bottom right until the page refreshes again.

There's a similar issue when trying to connect from multiple places at once. For example, if I try to connect to the notebook through my phone, chats only stay updated (without refreshing) for the device that sent the message. I believe its the same issue.

I'm assuming this causes issues as well if you want to have multiple sessions going on at once (pressing the + button, then starting a chat, then going back to a previous ongoing chat)
