Using the agent panel

The right panel is an in-memory conversation for the current NAWC server process. A sent prompt appears as a user message immediately, and follow-ups resume the same provider thread while the process is running. Restarting NAWC clears conversation history. Use the plus button for a clean conversation and the trash button to delete the current history.

Context

  • The active note is attached automatically, including its current saved content.
  • Type @ to attach a Git-backed project file.
  • Type $ to attach a generated or provider-discovered skill.
  • Paste or attach up to eight images when the provider advertises image support.
  • Use Fix with agent on a failed source block to attach its diagnostic.

Provider controls

Model, reasoning effort, and interaction modes come from the configured provider. Selections and unsent drafts are stored in browser local storage. While a turn runs, the send action becomes a stop action.

Reading a turn

Assistant Markdown forms one message even when the provider streams many events. Tool activity is grouped above the answer and can be expanded for output. Errors remain selectable and every message or code fence has a copy action. The timeline follows new output only while you remain at the bottom; otherwise a jump-to-latest control appears. Reuse places an earlier user prompt back in the composer for editing and resending.
