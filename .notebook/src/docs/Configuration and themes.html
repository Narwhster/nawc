Configuration and themes

nawc.config.ts is the composition root. defineConfig validates required plugins, provider, syntax list, and non-empty baseDir; it also validates ports from 1 through 65535.

If omitted, the editor is VS Code and the theme is nawcLight(). baseDir is resolved from the notebook project directory and defines the project visible to references, runners, editor links, and the provider.

Custom themes

A theme supplies a stable name, light/dark appearance, and CSS custom properties. Start by spreading the variables from nawcLight() or nawcDark(), then override only the tokens you own.
