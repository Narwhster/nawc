03. Configuration

Edit nawc.config.ts when you want to choose the notebook's plugins, agent provider, project directory, editor, theme, or server address.

Start with the generated configuration

import { defineConfig, nawcLight, vscode } from "nawc"; import { core } from "@nawc/core"; import { nawcSkills } from "@nawc/nawc-skills"; import { codex } from "@nawc/provider-codex"; import { typescript } from "@nawc/syntax-typescript"; import { vitest } from "@nawc/syntax-vitest"; export default defineConfig({ plugins: [core(), nawcSkills(), typescript(), vitest()], provider: codex(), editor: vscode(), theme: nawcLight(), baseDir: "..", });

Options

  • plugins enables note elements, agent skills, syntax support, and other extensions. Installing a package is not enough; add its plugin here.

  • provider selects the agent runtime. See [[docs/06-providers]] for the agent providers available by default and their options.

  • baseDir is the project directory used for source references, runnable examples, and editor links. It is resolved relative to the directory containing nawc.config.ts.

  • editor controls which editor opens a referenced source location. The default is vscode().

  • theme controls the notebook appearance. The default is nawcLight(); nawcDark() is also included.

  • port changes the server port. host changes the network interface it listens on. The command-line flags --port, --host, and --config override these values for one run.

Change the project location

Keep the notebook outside the source tree when possible. For a notebook in tools/notebook describing the repository root, use baseDir: "../..". Every file path in a <code> or <runnable> element is then written relative to that root.

Continue with [[docs/04-plugins]] to choose the features your notes need.
