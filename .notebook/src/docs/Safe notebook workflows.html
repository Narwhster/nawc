Safe notebook workflows

NAWC is a local developer tool, not a hostile-code sandbox. Its containment checks reduce accidental reach; providers, plugins, and runners remain trusted extensions.

Know the boundaries

  • Notes stay under the notebook's src directory.
  • References and runnable selections stay under baseDir; lexical traversal and symlink escapes are rejected.
  • baseDir must be within a Git worktree.
  • Interactive HTML runs in an iframe with sandbox="allow-scripts", without same-origin access to the parent editor.
  • Runner commands are argv arrays executed without a shell, but the selected program still has the server user's OS permissions.
  • Codex plan mode is read-only. Normal mode defaults to workspace-write unless configured read-only.

A review-friendly loop

  1. Use plan mode to refine a note or specification without edits.
  2. Keep taste-level, temporary implementation checks beside notebook examples rather than turning every preference into a permanent product test.
  3. Use <runnable> for the narrow check the agent should execute.
  4. Keep durable behavioral tests in the actual package test suite.
  5. Review the source diff and the explanatory note together, then run vp check and vp test from this repository.
