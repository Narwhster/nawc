04. Plugins

Plugins add capabilities to a notebook. Enable the plugins you need in the plugins array in nawc.config.ts.

Common plugins

  • core() adds <code>, <runnable>, and <interactive> note elements. Most notebooks should enable it.
  • nawcSkills() gives your configured agent the NAWC workflow and note-writing skills. Enable it when you want the agent to work with NAWC notes.
  • typescript() adds TypeScript and TSX source selection and execution.
  • vitest() adds references to and runnable examples for Vitest tests.
  • Other packages can add support for Java, JUnit, React, Tailwind, or a custom note element. Use the plugin's documentation for its package name and configuration.

Enable a plugin

import { core } from "@nawc/core";
import { nawcSkills } from "@nawc/nawc-skills";
import { typescript } from "@nawc/syntax-typescript";
import { vitest } from "@nawc/syntax-vitest";

export default defineConfig({
  plugins: [core(), nawcSkills(), typescript(), vitest()],
  // ...the rest of your configuration
});

Add the package to the notebook first, then add its factory to the array. Restart NAWC after changing the configuration so the new note elements and skills are loaded.

When to build a plugin

Build a plugin only when you need a capability that the available plugins do not provide, such as a custom HTML note element, a new source language, or an integration with another build tool. Keep the plugin's note syntax and usage instructions with that plugin so people can discover the options they can use.

Continue with [[docs/05-syntax]] to use source references and runnable examples.
