07. Editors and themes

Choose an editor

The editor setting controls where a source reference opens when you use its open action. The default is VS Code: 

import { vscode } from "nawc";

export default defineConfig({
  editor: vscode(),
  // ...the rest of your configuration
});

To use another editor, install an editor integration that provides one and set that editor in the configuration. A custom editor can open a file at the referenced line and column.

Choose a theme

Use the built-in light or dark theme, or start from one and change its name and CSS variables: 

import { nawcDark } from "nawc";

const theme = {
  ...nawcDark(),
  name: "midnight-copper",
  variables: {
    ...nawcDark().variables,
    "--primary": "oklch(0.72 0.16 45)",
    "--ring": "oklch(0.72 0.16 45)",
  },
};

export default defineConfig({
  theme,
  // ...the rest of your configuration
});

Use nawcLight() for a light appearance and nawcDark() for a dark appearance. Keep the existing variables when overriding a theme so the editor, terminals, and notebook controls remain styled consistently.
