Creating a plugin

A plugin has server-readable metadata and may optionally provide a browser client module. The definition names the plugin and may advertise custom nodes, syntax adapters, and generated agent skills.

When present, the package must make the client specifier resolvable from the notebook project. At startup NAWC resolves configured clients, generates a Vite virtual module, and loads the resulting client plugins into the editor. Syntax-only and skills-only plugins do not need a client.

Client module

Export a NawcClientPlugin: a name and an array of Tiptap extensions. A custom element normally needs a Tiptap node that defines parsing, rendering, attributes, and (when useful) a React node view.

The core plugin is the reference implementation: its server entry declares nodes, while its client implements editor rendering for interactive, ref, and runnable.

Add the plugin instance to plugins in nawc.config.ts. Skill synchronization refuses to overwrite an existing unmarked SKILL.md, so generated skills do not silently take ownership of user files.
