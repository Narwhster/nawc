Creating a syntax plugin

A syntax plugin gives <ref> blocks source intelligence and can optionally make <runnable> executable. Put its adapter in the plugin's syntax array; its canonical name and aliases are matched against the element's syntax attribute.

resolve receives already-read source and the selection attributes. Return selected code and one-based inclusive line numbers, or undefined when a requested symbol cannot be found. Whole-file fallback is useful when no name or type is supplied.

Adding execution

The example plugin's run method returns an argv array and working directory; it does not execute the process. Avoid shell strings. Treat every configured adapter as trusted code because its command runs with the NAWC server user's permissions.

The TypeScript adapter uses the compiler AST to find declarations and runs files through tsx. The Vitest adapter selects exact string-literal test names and runs Vitest with -t.
