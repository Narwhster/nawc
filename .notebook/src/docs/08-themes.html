08. Themes

The theme setting controls the notebook's color scheme. Import nawcLight or nawcDark from nawc and pass it to defineConfig.

Quick start

import { defineConfig, nawcLight } from "nawc"; export default defineConfig({ theme: nawcLight(), // ...the rest of your configuration });

Use nawcLight() for a light appearance and nawcDark() for a dark appearance. The default is nawcLight().

Creating your own theme

Create your own or customize an existing theme by spreading the built-in theme and overriding its name and variables.

import { defineConfig, nawcDark } from "nawc"; const theme = { ...nawcDark(), name: "midnight-copper", variables: { ...nawcDark().variables, "--primary": "oklch(0.72 0.16 45)", "--ring": "oklch(0.72 0.16 45)", }, }; export default defineConfig({ theme, // ...the rest of your configuration });

CSS variables

The following variable groups are available for customization.

UI surface

  • --background, --foreground

  • --card, --card-foreground

  • --popover, --popover-foreground

  • --primary, --primary-foreground

  • --secondary, --secondary-foreground

  • --muted, --muted-foreground

  • --accent, --accent-foreground

  • --destructive

  • --border, --input, --ring

Sidebar

  • --sidebar, --sidebar-foreground

  • --sidebar-primary, --sidebar-primary-foreground

  • --sidebar-accent, --sidebar-accent-foreground

  • --sidebar-border, --sidebar-ring

Typography

  • --radius — border radius for UI elements

  • --font-sans — base font family

  • --font-mono — monospace font family

Terminal

  • --terminal-selection — selection highlight color

Syntax highlighting

  • --syntax-keyword

  • --syntax-string

  • --syntax-number

  • --syntax-title
