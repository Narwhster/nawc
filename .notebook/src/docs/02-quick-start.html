02. Quick start

NAWC runs as a local notebook inside your project. The quickest setup creates a notebook subdirectory within your project and points it at the project root.

Requirements

  • Node.js 22.12 or newer.

  • A package manager: pnpm, npm, yarn, or Bun.

  • A Git repository for the project the notebook will describe.

  • An installed and authenticated agent provider, such as Codex, OpenCode, or Cursor.

Create a notebook

From the project directory, run:

pnpm create nawc .nawc
cd .nawc
pnpm nawc

The creator installs the dependencies and adds a starter configuration with the core note elements, agent skills, TypeScript and Vitest support, and the Codex provider. Replace the provider if you use a different agent runtime.

Open it

Open http://localhost:6292 in your browser. If that port is already in use, start NAWC with another one:

pnpm nawc --port 6300

Check the layout

.nawc/
  nawc.config.ts
  package.json
  src/
    Welcome.html
  .skills/

Notes are HTML files under src/. The generated .skills/ directory contains the skills supplied by your configured plugins. It is generated while NAWC runs and should stay out of version control.

The generated baseDir: ".." points from .nawc/ to the project directory above it. Change baseDir if your notebook lives somewhere else. Source paths in notes are resolved from that project directory, not from the note's own folder.

Add your first note

Create another HTML file anywhere under src/, then link to it from another note with a wiki-link such as [[notes/plan]]. The core plugin adds three elements for richer notes: live source references, runnable source examples, and sandboxed interactive prototypes.

Continue with [[docs/03-configuration]] to adjust the notebook, or return to [[docs/01-introduction]] to learn the workflow.
