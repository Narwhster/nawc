02. Quick start

NAWC runs as a local notebook inside your project. The quickest setup creates a notebook subdirectory within your project and points it at the project root.

Requirements

  • Node.js 22.12 or newer.

  • A package manager: pnpm, npm, yarn, or Bun.

  • A Git repository for the project the notebook will describe.

  • An installed and authenticated agent provider, such as Codex, OpenCode, or Cursor.

Create a notebook

From the project directory, run:

pnpm create nawc

The creator walks you through a series of interactive prompts:

  • Directory — where to create the notebook (defaults to nawc-notebook).

  • Package manager — npm, pnpm, yarn, or bun (auto-detected from your environment).

  • Provider — Codex, Cursor, Opencode, or Pi.

  • Editor — VS Code, Cursor, CLion, IntelliJ IDEA, WebStorm, or Zed.

  • Theme — Light or Dark.

  • Base directory — the path notes use to reach project source files (defaults to ..).

  • Plugins — multiselect from available plugins; defaults to Core.

You can skip any prompt by passing the corresponding flag instead, for example:

pnpm create nawc .nawc --provider opencode --editor vscode --theme dark --plugins core,typescript,vitest

Once the prompts finish, the creator writes the boilerplate files, installs dependencies, and prints a success message. Then start the notebook:

cd .nawc pnpm nawc

Open it

Open http://localhost:6292 in your browser. If that port is already in use, start NAWC with another one:

pnpm nawc --port 6300

Check the layout

.nawc/ nawc.config.ts package.json src/ Welcome.html .skills/

Notes are HTML files under src/. The generated .skills/ directory contains the skills supplied by your configured plugins. It is generated while NAWC runs and should stay out of version control.

The generated baseDir: ".." points from .nawc/ to the project directory above it. Change baseDir if your notebook lives somewhere else. Source paths in notes are resolved from that project directory, not from the note's own folder.

Add your first note

Notes are plain HTML files living under src/. Create new notes from the NAWC UI and link between them with wiki-links such as [[docs/03-configuration]].

Continue with [[docs/03-configuration]] to learn how to customize the notebook further, or return to [[docs/01-introduction]] to learn the workflow.
