05. Source references and runnable examples

The <code> element shows source from your project. The <runnable> element shows source and adds a control for running it when the selected syntax supports execution. Both use paths relative to baseDir.

Learning the syntax is useful for debugging mistakes, but I recommend letting your agent add these.

Without file, the <code> element stores inline source directly in the note instead of referencing a file. Escape HTML characters in inline source.

<code syntax="ts">const answer = 42;</code>

Example - TypeScript

Enable typescript(), then use typescript, ts, or tsx as the syntax name:

<code file="src/format.ts" syntax="typescript" name="formatDate" type="function" /> <runnable file="examples/format-date.ts" syntax="ts" />

A reference without name and type shows the whole file. To select one declaration, provide both. TypeScript supports function, class, type, interface, variable, and enum.

A runnable TypeScript file runs with tsx. Declaration selectors do not change what is executed, so put the example you want to run at the file's top level.

Here is an inline runnable you can try directly in the notebook:

const greeting = "Hello from NAWC!"; console.log(greeting);

Other languages

Vitest, Java, Rust, and other syntax plugins use their own syntax names and selectors. Let your agent read the generated skill for the plugin before adding creating code blocks for them. The names and selectors are not interchangeable.

nawc splash

nawc splash lists notes whose <code>, <runnable>, or <interactive> references point at files modified in your working tree. Tell your agent to run it after making changes to find notes that might be stale, or before committing to check if any docs need updating alongside the code.

nawc splash nawc splash --depth 1

With --depth N, the command also follows outgoing wiki-links from splash zone notes, then the links of those notes, up to N hops. The default depth is 0.

The output has two sections. The splash zone lists notes whose references touch a modified file. The related section shows wiki-link chains starting from those notes.

# Splash Zone - docs/05-syntax.html # Related - Depth 1 - docs/05-syntax.html references docs/04-plugins.html, docs/06-providers.html

Continue with [[docs/06-providers]] to connect the agent that will work with your notes.
