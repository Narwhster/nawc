05. Source references and runnable examples

The <ref> element shows source from your project. The <runnable> element shows source and adds a control for running it when the selected syntax supports execution. Both use paths relative to baseDir.

TypeScript

Enable typescript(), then use typescript, ts, or tsx as the syntax name: 

<ref
  file="src/format.ts"
  syntax="typescript"
  name="formatDate"
  type="function"
/>

<runnable file="examples/format-date.ts" syntax="ts" />

A reference without name and type shows the whole file. To select one declaration, provide both. TypeScript supports function, class, type, interface, variable, and enum.

A runnable TypeScript file runs with tsx. Declaration selectors do not change what is executed, so put the example you want to run at the file's top level.

Vitest

Enable vitest(), then use vitest or test: 

<ref file="src/math.test.ts" syntax="vitest" name="adds numbers" />
<runnable file="src/math.test.ts" syntax="test" name="adds numbers" />

The test name must match exactly. Without a name, a reference shows the whole test file and a runnable block runs all tests in that file. With a name, the runnable block runs only that title.

Other languages

Java, JUnit, and other syntax plugins use their own syntax names and selectors. Read the generated skill for the plugin before adding attributes; the names and selectors are not interchangeable.
