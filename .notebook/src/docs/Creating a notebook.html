Creating a notebook

A NAWC notebook is a small Node project whose notes are HTML files in src/. The quickest starting point is the scaffold produced by create-nawc; the checked-in example shows the complete shape.

Minimum layout

.notebook/
  package.json
  nawc.config.ts
  src/
    Welcome.html

Install nawc, @nawc/core, a provider, and whichever syntax adapters the notes need. Add a script such as "dev": "nawc", then run it from the notebook directory.

Write live notes

Ordinary HTML is editable in the notebook. The core plugin adds three useful elements:

  • <ref file="src/api.ts" syntax="ts" name="createApi" type="function"></ref> displays live source.
  • <runnable file="examples/demo.ts" syntax="ts"></runnable> displays and runs a file.
  • <interactive>...</interactive> embeds an HTML prototype in a sandboxed iframe.

Paths resolve against baseDir, not against the note. Wiki links such as [[Architecture]] connect notes without duplicating explanations.
