07. Editors

The editor setting controls where a source reference opens when you click its open action. Set it in nawc.config.ts with an editor factory from one of the editor packages.

Configuration

Import the editor factory and pass it to defineConfig. The editor package must be installed in the notebook before it can be imported.

import { vscode } from "@nawc/editor-vscode"; export default defineConfig({ editor: vscode(), // ...the rest of your configuration });

Supported editors

  • vscode (@nawc/editor-vscode) — opens via vscode:// URL or the code CLI when reveal is set.

  • cursor (@nawc/editor-cursor) — opens via the cursor CLI.

  • zed (@nawc/editor-zed) — opens via zed:// URL.

  • idea (@nawc/editor-idea) — opens via the idea CLI.

  • webstorm (@nawc/editor-webstorm) — opens via the webstorm CLI.

  • clion (@nawc/editor-clion) — opens via the clion CLI.

Editors that use a CLI command need the editor's shell launcher installed and on your PATH.

Creating your own editor

An editor is an object that implements the NawcEditor interface. The open method receives the file location and returns either a url (opened by the platform) or a command (spawned directly).

import type { NawcEditor } from "@nawc/config"; export function myEditor(): NawcEditor { return { name: "my-editor", label: "My Editor", open({ file, line, column }) { return { type: "command", command: ["my-editor", line ? `${file}:${line}:${column ?? 1}` : file], }; }, }; }
