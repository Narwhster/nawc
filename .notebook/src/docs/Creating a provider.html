Creating a provider

A provider connects the prompt panel to an agent harness without coupling the server to that harness. Implement NawcProvider and return an async iterable of normalized events.

Events may be thread.started, message, command, error, or done. Optional listSkills and listModels populate the composer. References distinguish project files from generated or provider-discovered skills.

Codex as a worked example

The Codex adapter invokes codex exec --json, translates JSONL events, supplies the configured working directory, and tells Codex where generated plugin skills live. Plan mode forces a read-only sandbox; normal mode defaults to workspace-write. Options can choose the executable, default model, or a stricter read-only sandbox.

Prefer argv-based process APIs, preserve provider errors as visible error events, and never interpret prompt text as a shell command.
