NAWC, explained by NAWC

NAWC is a notebook that lives beside your code. Its notes are ordinary HTML, but they can point at live source, run focused examples, host interactive prototypes, and give coding agents a persistent place to explain or refine their work.

The gap it closes

  1. Reviewing agent-written code. An agent can leave an explanation connected to the implementation instead of asking a developer to reconstruct its reasoning from a diff.
  2. Thinking together before implementation. Notes provide durable, disposable space for plans, prototypes, and runnable sketches without mixing them into production code.
  3. Keeping specifications without keeping throwaway tests. Implementation-shaping examples can live beside a note and be run while the feature is built; the product test suite can stay focused on lasting behavior.

This notebook applies that idea to NAWC itself. It is both a guided tour and an example of the artifact the repository produces.
